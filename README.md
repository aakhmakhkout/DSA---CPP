# DSA in C++

My practice code while learning data structures and algorithms in C++. It starts from language basics and moves into arrays, vectors, and a few classic array problems. Each folder covers one topic.

## Contents

| Folder | Topic |
|---|---|
| `2_var,data-types,opt's` | Variables, data types, operators |
| `3_cond_stt_loops` | Conditional statements and loops |
| `4_patterns` | Pattern printing |
| `5_Functions` | Functions |
| `6_BNS` | Binary number system |
| `7_bitwise opt` | Bitwise operators |
| `8_arrays` | Arrays |
| `9_vectors` | Vectors (STL) |
| `10_kadanes algo` | Kadane's algorithm (maximum subarray sum) |
| `11_majority element` | Majority element |

## Running a file

Needs a C++ compiler such as `g++`.

```bash
g++ filename.cpp -o output
./output
```

On Windows, run `output.exe` instead of `./output`.

## Notes

- Folders are numbered in the order I worked through them.
- The code is practice-level: written to understand the concept first, not optimized or production-ready.
- More topics will be added as I go.
